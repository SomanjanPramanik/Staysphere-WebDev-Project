# StaySphere — Property Listing & Management Portal

A full-stack web application built using the MVC architecture with **Node.js**, **Express.js**, **MongoDB (Mongoose)**, and **EJS** server-side rendering.

## Key Features
* **RESTful CRUD Architecture:** Complete Create, Read, Update, and Delete workflows for property listings using `method-override` for PUT and DELETE HTTP verbs.
* **Centralized Error Handling:** Custom higher-order `asyncWrap` middleware to catch asynchronous Mongoose/database exceptions cleanly without crashing the server.
* **Dynamic Server-Side Rendering:** Modular EJS views for listing catalogs, detailed property pages, and interactive forms.

## Tech Stack
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose ODM
* **Templating Engine:** EJS# Staysphere-WebDev-Project
